Eaton-boksen: få kontakt

Følg stega i rekkjefølgje. Trykk Kopier og lim inn i cmd med høgreklikk.

Ikkje rør desse på Eaton-sida: Software Update, Device Reset og Restore. Hald deg unna skrueklemmene i skapet (230 V).

1Start boksen på nytt

  1. Sjå at nettverkskabelen sit godt i Eaton-boksen.
  2. Dra ut den raude straumkabelen, vent 10 sekund, set han inn att.
  3. Vent 2 minutt.

2Leit etter boksen

  1. På PC-en: Innstillingar → Nettverk og Internett → Wi-Fi → Stene → IP-tilordning → Rediger → Automatisk (DHCP) → Lagre.
  2. Trykk Windows-tasten, skriv cmd, trykk Enter.
  3. Kopier denne og noter Standard gateway og nettmaske. Du skriv dei inn i steg 5:
ipconfig | findstr /i "IPv4 mask gateway"
  1. Kopier denne, lim inn, trykk Enter. Vent om lag eitt minutt:
(for /L %i in (1,1,254) do @ping -n 1 -w 100 192.168.50.%i >nul) & arp -a | findstr 00-40-9d
Kjem det ei linje med 00-40-9d-78-9d-ab? Talet til venstre er adressa til boksen. Gå til steg 4.

Kjem det ingenting? Gå til steg 3.

3Prøv den gamle adressa

  1. Innstillingar → … → Wi-Fi → Stene → IP-tilordning → Rediger → Manuell → slå på IPv4:
    • IP-adresse: 192.168.42.10
    • Nettmaske: 255.255.255.0
    • Resten tomt → Lagre
  2. Kopier denne inn i cmd:
ping 192.168.42.30
  • «Svar fra …»: boksen lever. Adressa er 192.168.42.30. Gå til steg 4.
  • «Tidsavbrudd»: boksen svarar ikkje. Gjer steg 1 éin gong til.

4Opna nettverkssida

  1. Opna Edge. Skriv http:// + adressa, til dømes http://192.168.42.30/
  2. Logg inn med brukarnamn og passord frå etiketten under boksen.
  3. Trykk Network Settings. Står det https:// i adresselinja, endra til http://.
  4. Ta skjermbilete av heile sida. Ikkje endra noko enno.

5Spør KI-en

Fyll inn felta. Meldinga under blir oppdatert, og du sender ho til Claude saman med skjermbiletet av Network Settings.

Eg legg òg ved skjermbilete av (sjå steg 7):

7Andre stader i innstillingane (valfritt)

    
Same framgangsmåte: ta skjermbilete, kryss av i steg 5, og la KI-en seia kva som bør endrast.
