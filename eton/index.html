Eaton-boksen: få kontakt

Mål: gi Eaton ECI-LAN-boksen fast adresse 192.168.50.250 på nettet på hytta. Berre Network Settings skal endrast.

1Start boksen på nytt

  1. Sjå at nettverkskabelen sit godt i Eaton-boksen.
  2. Dra ut den raude straumkabelen, vent 10 sekund, set han inn att.
  3. Vent 2 minutt.

2Prøv den gamle adressa

  1. Opna cmd.
  2. Kopier denne og noter Standard gateway og nettmaske. Du skriv dei inn i steg 5:
ipconfig | findstr /i "IPv4 mask gateway"
  1. Sjekk at den nye adressa til boksen er ledig:
ping -n 2 192.168.50.250

«Tidsavbrudd» = ledig, bra. Svarar noko, bruk 192.168.50.249 i staden og sjekk den på same måte.

  1. Innstillingar → Nettverk og Internett → Wi-Fi → nettet på hytta → IP-tilordning → Rediger → Manuell → slå på IPv4:
    • IP-adresse: 192.168.42.10
    • Nettmaske: 255.255.255.0
    • Resten tomt → Lagre
  2. Opna Edge og skriv http://192.168.42.30/
Kjem det ei innloggingsside? Boksen lever. Gå til steg 4.

Lastar ikkje sida? Kopier denne inn i cmd for å sjå kvifor:

ping -n 2 192.168.42.30
  • «Svar fra …»: boksen lever, det er nettlesaren. Sjå at det står http:// og ikkje https://, og prøv igjen.
  • «Tidsavbrudd»: gå til steg 3.

3Leit etter boksen på heimenettet

  1. Innstillingar → … → Wi-Fi → nettet på hytta → IP-tilordning → Rediger → Automatisk (DHCP) → Lagre.
  2. Kopier denne inn i cmd. Vent om lag eitt minutt:
(for /L %i in (1,1,254) do @ping -n 1 -w 100 192.168.50.%i >nul) & arp -a | findstr 00-40-9d
Kjem det ei linje med 00-40-9d? Talet til venstre er adressa til boksen. Gå til steg 4.

Kjem det ingenting? Gjer steg 1 éin gong til, og prøv steg 2 og 3 på nytt.

4Opna nettverkssida

  1. Er du ikkje alt der: opna Edge og skriv http:// + adressa, til dømes http://192.168.42.30/
  2. Logg inn med brukarnamn og passord frå etiketten under boksen.
  3. Trykk Network Settings. Står det https:// i adresselinja, endra til http://.
  4. Ta skjermbilete av sida slik ho er no, i tilfelle du må tilbake.

5Fyll inn og lagra

FeltVerdi
IP-oppsett (DHCP / Static)Static
IP address192.168.50.250 (eller .249 frå steg 2)
Subnet mask255.255.255.0
Default gateway192.168.50.1 (eller det ipconfig viste)
DNS (om feltet finst)same som gateway

Alt anna lèt du stå. Trykk Save eller Apply.

Ser sida annleis ut enn dette? Bruk reserven nedst på sida.

6Etter at du har lagra

  1. Sida mistar kontakten, sidan boksen no har ny adresse.
  2. Set PC-en tilbake til Automatisk (DHCP) som i steg 3.
  3. Opna http://192.168.50.250/ i Edge (eller .249 om du brukte den). Kjem du inn, er alt klart.

Lastar ikkje sida? Kopier denne inn i cmd:

ping -n 2 192.168.50.250

Svarar han, er det nettlesaren (sjekk http://). Svarar han ikkje, ventar du eitt minutt og prøver igjen.

  1. Skriv adressa i feltet «Actual IP Address» på etiketten under boksen.

Reserve: spør KI-en

Berre om sida ser annleis ut enn i steg 5. Fyll inn felta. Meldinga under blir oppdatert, og du sender ho til Claude saman med skjermbiletet av Network Settings.


    
Gjer det KI-en seier, og ta nytt skjermbilete før du trykkjer Save.
